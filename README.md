
# Habit Tracker

A simple habit tracking web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Add daily habits with target goals (1-7 days per week)
- Mark habits as done and track streaks
- Categorize habits (Health, Fitness, Learning, Work, Other)
- View daily progress with completion percentage
- Delete habits

## How to use

1. Open `index.html` in your browser
2. Add a new habit with a name, target days, and category
3. Check off habits as you complete them
4. Watch your streak grow!

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
